# Données de secours synthétiques

`incident.jsonl` contient uniquement des événements fictifs de ShopLab. Il sert au TD04/TP07 si le profil `observe` ne peut pas tourner sur un laptop à faible mémoire. Aucun token, cookie, mot de passe ou identifiant réel n’y figure.

Une analyse offline doit être marquée comme telle; elle ne remplace pas un test runtime dans le rapport QA.
